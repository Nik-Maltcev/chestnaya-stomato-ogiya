# Дизайн-система версии 3 — «ЧЕСТНАЯ · Technical Identity»

Дата: 2026-11-13. Область применения: `version-3.html` + `css/styles-v3.css`.
Контент и функционал не меняются: те же разделы, фильтры, калькулятор, запись, маска телефона, до/после, FAQ, юридическая модалка, тосты, счётчики, scrollspy, мобильное меню и sticky-CTA.

---

## 1. Резюме концепции

Айдентика бренда (глубокий тёмно-синий + ледяной голубой + тонкая линия рукопожатия) подана не как «медиум-премиум с плашками», а как **разворот брендбука / технический паспорт клиники**:

- почти монохром: чернила на бумаге, один холодный акцент;
- типографика делает всю работу — размер, вес, трекинг, регистр;
- сетка видна: hairline-линии (1 px) вместо теней, плашек и скруглений;
- крупные заглавные заголовки + моноширинные микро-подписи (номерация, цены, лейблы);
- инверсные тёмные полосы задают ритм вместо «разноцветных секций»;
- рукопожатие — единственный «человечный» графический приём, крупно и один-два раза, а не иконка на каждой карточке.

Эмоция: **инженерная честность**. Обещание не «мы заботливые», а «у нас всё написано, посчитано и подписано».

### Чем v3 отличается от v1 и v2

| | v1 «Классика» | v2 «Айдентика» | v3 «Technical Identity» |
|---|---|---|---|
| Фон | холодный голубой, мягкие градиенты | ледяная голубая плоскость, сетка колонок | **бумажный off-white, инверсные navy-полосы** |
| Глубина | тени, скругления | плоскость, 1 px рамки | **плоскость, hairline-разлиновка, ноль теней** |
| Радиусы | 12–24 px | 2–5 px | **0 px** |
| Типографика | Manrope, полужирный | Manrope 800, CAPS, подчёркивание | **Golos Text 800 CAPS + JetBrains Mono микро-типографика** |
| Акцент | голубой + мятный | navy + голубое подчёркивание | **один navy + лёд только как подсветка** |
| Логотип | иконка-зуб | png-знак и вордмарк | **типографический вордмарк + большое line-art рукопожатие** |
| Моушен | мягкие reveal | reveal + hover | **reveal + mega-marquee + hover-invert** |

## 2. Что взяли из трендов 2026 (и что не взяли)

**Взято:**

1. **Typography as Design** — oversized headline, гротеск, плотный трекинг, герой без «стоковой» фотографии как центра композиции.
2. **Technical Monospace** — моноширинные лейблы, hairline-бордеры, плотные табличные блоки, «терминальная» аккуратность.
3. **Swiss grid** — сетка организует связи; масштаб/вес/интервал заменяют декор; один выразительный акцент; воздух как конструкция; одна выразительная интеракция.
4. **Minimalism 2.0 / warm minimal** — не чистый белый, а «топлёное молоко» / «светлый бетон»: `#F6F7F8`, `#EFF2F4`.
5. **Dark canvas** — инверсные секции на navy (не на чёрном), светлый текст, один акцент.
6. **Visibly human-made** — рукопожатие тонкой линией как авторский след против фотостока.
7. **Motion as narrative** — скролл-раскрытие по стадиям, без параллакс-блобов и «прыгающих» карточек.

**Не взяли осознанно:** 3D-сцены, glassmorphism/«живое стекло», бенто-плашки со скруглениями, ретро-пиксель, геймификация, курсор-прожектор, AI-персонализация. Причина: для клиники это размывает доверие и противоречит «паспортной» строгости айдентики.

## 3. Цвета

### 3.1 Токены

```css
--ink:        #042744;  /* чернила: основной текст, заголовки, fills */
--ink-2:      #3C5568;  /* вторичный текст */
--ink-3:      #64798A;  /* третичный, микро-подписи (AA на paper) */
--paper:      #F6F7F8;  /* базовый фон, НЕ #fff */
--paper-2:    #EFF2F4;  /* чередующиеся секции */
--paper-3:    #E4E9ED;  /* заполнение hairline-блоков, track */
--line:       #C9D6DF;  /* solid hairline */
--line-soft:  rgba(4,39,68,.14);  /* hairline на светлом */
--accent:     #185F88;  /* бренд-синий: ссылки, фокус, активный таб */
--ice:        #7FC0E3;  /* лёд: подчёркивание, подсветка на тёмном */
--signal:     #2E8B72;  /* «открыто/включено», зелёный индикатор */
--warn:       #B4562B;  /* ошибки валидации */

/* инверсная полоса */
--dark:       #042744;
--dark-2:     #06304F;  /* второй слой на тёмном */
--on-dark:    #E8F1F7;
--on-dark-2:  #A9C2D4;
--line-dark:  rgba(232,241,247,.20);
```

### 3.2 Роли

| Роль | Правило |
|---|---|
| Чернила | текст, кнопки primary, заливки «важно», инверсные секции |
| Бумага | всё остальное. Чистого белого нет нигде |
| Hairline | единственное средство разделения. 1 px, всегда |
| Акцент `--accent` | только интерактив: фокус, активный фильтр, ссылка, курсор слайдера |
| Лёд `--ice` | декоративная подсветка на тёмном и подчёркивание; текст на нём не набирается |
| Сигнал/варнинг | статусы и валидация, не более |

### 3.3 Плотность цвета

- светлые секции: ≥ 92 % чернил/бумаги/hairline, ≤ 3 % акцента;
- тёмные секции (booking, манифест-полоса, футер): navy + `--on-dark` + hairline-dark + лёд;
- запрет: градиенты-«соки», цветные подложки под каждую карточку, второй брендовый цвет.

### 3.4 Контраст (WCAG AA, нормальный текст)

| Пара | Ratio | Статус |
|---|---|---|
| `--ink` / `--paper` | ≈ 13.4:1 | AAA |
| `--ink-2` / `--paper` | ≈ 7.0:1 | AA |
| `--ink-3` / `--paper` | ≈ 4.7:1 | AA (только мелкий вторичный) |
| `--accent` / `--paper` | ≈ 6.1:1 | AA |
| `--on-dark` / `--dark` | ≈ 12.6:1 | AAA |
| `--on-dark-2` / `--dark` | ≈ 7.4:1 | AA |
| белый / `--accent` | ≈ 6.1:1 | AA |

## 4. Типографика

### 4.1 Семейства

| Роль | Семейство | Запасное | Cyrillic |
|---|---|---|---|
| Display + body | `Golos Text` (400/500/600/700/800) | `Inter, system-ui, sans-serif` | да |
| Микро-типографика, числа, лейблы | `JetBrains Mono` (400/500/700) | `ui-monospace, SFMono-Regular, monospace` | да |

Оба — нативная кириллица. Никаких засечек и «декоративных» шрифтов: в v3 декором работает сетка и масштаб.

### 4.2 Шкала (fluid, ratio ≈ 1.25)

| Токен | Значение | Применение |
|---|---|---|
| `--fs-display` | `clamp(3.1rem, 8.4vw, 7.6rem)` | H1 героя, mega-вордмарк |
| `--fs-h2` | `clamp(2rem, 4.6vw, 3.5rem)` | заголовки секций |
| `--fs-h3` | `clamp(1.35rem, 2.1vw, 1.85rem)` | подзаголовки, цитаты |
| `--fs-h4` | `1.05rem` | названия карточек/услуг |
| `--fs-lead` | `clamp(1rem, 1.25vw, 1.15rem)` | лиды |
| `--fs-body` | `.95rem` / line-height 1.65 | текст |
| `--fs-sm` | `.82rem` | подписи, caption |
| `--fs-micro` | `.66rem` | mono-лейблы, uppercase |
| `--fs-num` | `clamp(2.2rem, 4.4vw, 3.4rem)` | счётчики, итог сметы |

### 4.3 Правила набора

1. **Display и H2: ALL CAPS**, вес 800, `letter-spacing: -.045em`, `line-height: .92–1.0`. Ключевая фраза — вторым регистром (обычный sentence case) и/или льдом, чтобы создать контраст регистров.
2. **Микро-подписи: mono, ALL CAPS**, `letter-spacing: .14em`, вес 500, цвет `--ink-3`. Это «подписи в паспорте»: eyebrow, лейблы полей, статусы, счётчики фильтров.
3. **Номера секций**: mono, `decimal-leading-zero`, рисуются CSS-счётчиком (`01 … 08`) перед eyebrow. В HTML не дублируются.
4. **Числа и цены**: mono + `font-variant-numeric: tabular-nums`, знак `₽` через `&nbsp;`, дробные/диапазоны не переносить.
5. **Body**: вес 400–450, max-width строки 62–68 символов, выравнивание левое (кроме героя, где композиция центровано-блочная).
6. Запрет: курсив «для красоты», засечки, градиентный текст, text-shadow, более двух гарнитур на экране.

### 4.4 Иерархия «три голоса»

```
MONO-ЛЕЙБЛ   01 / ЧЕСТНЫЙ МАНИФЕСТ        ← что это за раздел
DISPLAY      ПРИНЦИПЫ, А НЕ ОБЕЩАНИЯ     ← аргумент раздела
BODY         Один-два предложения…        ← объяснение
```

## 6. Компоненты

### 6.1 Общие свойства поверхностей

| Свойство | Значение |
|---|---|
| radius | `0` везде (кнопки, поля, карточки, модалки, тосты, изображения) |
| border | `1px solid var(--line-soft)`, только когда нужно |
| shadow | нет. Ни одной тени |
| hover | смена фона на чернила/бумагу, underline-свип, сдвиг ≤ 2 px |
| transition | `160–260ms cubic-bezier(.22,.61,.36,1)` |
| focus-visible | `2px solid var(--accent)`, `outline-offset: 2px` |

### 6.2 Шапка

- верхняя **spec-полоса** (mono, 26 px): адрес слева, «сейчас работаем» с `--signal`-точкой справа; на ≤900 скрывается;
- тип-вордмарк: `ЧЕСТНАЯ` (800, -.04em) над `С ТО М А ТО Л О Г И Я` (500, .28em, `--ink-3`) — айдентика передана набором, без png;
- nav: mono-micro 0.66rem, uppercase, underline-свип слева направо, активный пункт — жирный + 2 px нижняя линия `--accent`;
- телефон mono tabular; CTA — квадратная primary;
- при скролле: высота не «сжимается», меняется только фон на плотный и появляется hairline снизу.

### 6.3 Кнопки

| Тип | Стиль |
|---|---|
| `btn-primary` | чернила, бумага-текст, hover → `--accent` |
| `btn-light` | прозрачная, 1 px чернила, hover → заливка чернилами, текст бумагой |
| `btn-sky` | `--ice` на тёмном, текст чернилами |
| размер | высота 44 px (lg 54), padding-inline 22, mono-uppercase-лейбл 0.7rem `.1em` |
| иконка | стрелка сдвигается на 3 px при hover |

### 6.4 Фильтры услуг

- не «пилюли»: горизонтальный ряд mono-табов, разделённых hairline, активный — заливка чернилами;
- справа от названия — счётчик карточек (`TER 04`), mono, `--ink-3`;
- на ≤768 — горизонтальный скролл с видимым обрезанным краем (паттерн «dense data»), без переноса в 3 ряда.

### 6.5 Карточка услуги = строка реестра

- слева mono-код категории, справа цена mono tabular;
- hairline снизу, hover: фон `--paper-3` + смещение цены;
- чек-лист: 1 px маркеры, без цветных галочек-иконок;
- `chip` — mono uppercase, 1 px рамка, без фона.

### 6.6 Калькулятор сметы

- инверсная navy-полоса, hairline-разлиновка строк;
- `+/−` — квадратные mono-кнопки 30 px, hover → лёд;
- итог: `--fs-num`, mono tabular, с права — «₽»; ниже mono-сноска «предварительно · фиксируется договором»;
- кнопка PDF — `btn-sky`.

### 6.7 Врачи

- фото 1:1, кроп по груди, `filter: grayscale(.35) contrast(1.05)`; hover → цвет полностью;
- имя: 700, uppercase, 1.05rem; роль: mono-micro;
- карточка без рамки: hairline снизу 2 px чернилами + hairline сверху 1 px;
- слоты записи — mono-строка с `--signal`-точкой.

### 6.8 Отзывы и до/после

- крупная выноска-цитата (`--fs-h3`, sentence case) — единственный «человечный» текст;
- карточка кейса: hairline-рамка, mono-мета (возраст, услуга, срок), цена mono tabular;
- слайдер до/после: квадратная ручка 44 px, 1 px чернила + 2 линии-«штрихи», подпись `ДО/ПОСЛЕ` mono;
- рейтинг: mono `4.9 / 5.0`, звёзды не закрашиваем полностью — outline-звёзды.

### 6.9 FAQ

- строки-аккордеон с hairline, номер `01` mono слева, `+`/`−` mono справа;
- при открытии фон `--paper-2`, вопрос не меняет размер;
- одна колонка, max-width 900 px, отступ ответа выровнен по левой сетке (не по тексту вопроса).

### 6.10 Запись (booking)

- инверсия `--dark` + видимая колонками сетка;
- слева — заголовок display + mono-контакты; справа — форма на бумаге (контраст «белый лист на синем столе»);
- поля: underline-стиль (без рамок-коробок), label mono-micro, focus → 2 px `--accent` снизу;
- чекбокс согласия — квадратный, `accent-color: var(--ink)`;
- success-панель: hairline-рамка, `--signal` маркер, mono-номер заявки.

### 6.11 Футер

- navy, в самом верху — статичный **mega-вордмарк** `ЧЕСТНАЯ СТОМАТОЛОГИЯ` (display, outline-обводка через `-webkit-text-stroke`, прозрачная заливка, `aria-hidden`); анимированный marquee остаётся только в hero-полосе;
- колонки: mono-заголовки, ссылки бумага-2;
- лицензия — hairline-блок, mono-номер;
- нижняя строка: mono-micro, копирайт слева, «Политика» справа.

### 6.12 Тосты, модалка, мобильное меню

- тост: бумага, hairline 1 px чернила слева 3 px, mono-заголовок, без тени;
- модалка: затемнение `rgba(4,39,68,.55)`, панель бумага, radius 0, header hairline;
- мобильное меню: full-screen бумага, ссылки display-uppercase 1.6rem с mono-номерами, низ — sticky CTA чернилами.

## 9. Доступность

- keyboard: все интерактивы достижимы, focus-visible 2 px `--accent`, ловушка фокуса в модалке, `Esc` закрывает;
- contrast: таблица 3.4 обязательна для новых пар;
- tap targets ≥ 44 px (мобильные `+/−` увеличены до 40 px + 4 px padding);
- `aria-current` у активного фильтра, `aria-expanded` у FAQ/меню, `aria-live="polite"` у итога сметы и тостов;
- изображения — осмысленный `alt`, декоративные `aria-hidden`;
- текст не масштабируется `px`-только: базовый `rem`, при 200 % зуме сетка не ломается, горизонтального скролла нет;
- `prefers-reduced-motion` и `prefers-contrast` (в последнем — hairline → 2 px, лёд → чернила).

## 10. Do / Don't

**Do**

- начать любой экран с hairline-разлиновки и mono-лейбла — «документ», потом картинка;
- держать один акцент на экран;
- делать инверсию только для смыслового пика (смета, запись, футер);
- заменять тень — линией, заменять скругление — отступом;
- проверять: «если убрать цвет, останется ли иерархия?» — должна остаться.

**Don't**

- не возвращать блобы, glassmorphism, бенто-скругления, серифы;
- не делать карточку с тенью «как в v1»;
- не ставить png-логотип v2 в шапку — здесь вордмарк набирается;
- не красить чипсы/иконки в «приятный голубой» — акцент только на интерактив;
- не добавлять второй шрифт «для акцента».

## 11. План внедрения (маппинг на код)
